# Person Identification by skeleton

That's application for identification the person by skeletal data. The main idea is using the Activity profiles [I'll attach the reference]

## Installation 

1. Before install this service you have to get Kinects Studio SDK 2.0 from official Microsoft site: https://www.microsoft.com/en-us/download/details.aspx?id=44561
2. Connect Kinect to your computer by USB 3.0
3. Download and use service
